A token launch radar: 198 pre-token protocols from a sealed DefiLlama snapshot, ranked by an implied value calibrated from the live-token protocols in the same snapshot (median market-cap-to-TVL ratio per category), each with a seven-step farm plan. The dashboard is sortable and filterable, with a detail view per protocol showing the model's inputs, its live-token comparables and its farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
